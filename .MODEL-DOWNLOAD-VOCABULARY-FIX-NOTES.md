# Model download and vocabulary correction — current status

Scope: `swar-sadhika-test` only. Do not copy these changes to `anujadha`.

## Current implementation

The former custom runtime enforced `VOCAB_SIZE = 1039` and rejected the supplied bank's `vocab_char_map` (2,545 character IDs). Reviewing the official browser source archive showed that its actual synthesis path directly uses `bankManifest.vocab_char_map`, combines reference IDs with one character ID per input character, and writes `rawTokens[i] + 1` to the `text_in` tensor. The old generic vocabulary gate did not implement that upstream contract.

`vendor/vagdhenu-upstream/vagdhenu-onnx.js` now contains the self-contained official browser bundle from the supplied archive's `dist/index.mjs`, with two integration-specific cache adjustments: a shared Swar-Sadhika cache namespace, and `ignoreSearch: true` on cache reads so versioned bank URLs can reuse the already verified artifact.
